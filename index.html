AutoSearchEngine

直接编辑或新增你自己的搜索引擎，自动生成一行可粘贴脚本。导入 / 导出 JSON，复制脚本，然后在 Edge 内置搜索引擎页面的 Console 里运行即可。

1 · 配置 / Configure修改预设，或新增自己的 Name / Shortcut / URL。
2 · 复制 / Copy页面自动生成一行脚本，点一下即可复制。
3 · 粘贴 / Paste打开 Edge 搜索引擎设置，Ctrl+Shift+J，粘贴执行。

搜索引擎 / Search Engines

下面的列表可以直接编辑。关闭左侧勾选可暂时排除某一项，不会从列表删除。

启用名称快捷键搜索 URL（用 %s 表示关键词）

一行导入脚本 / One-line Import Script

脚本会自动操作 Edge 自带的 “Add search engine” 对话框，不直接修改 SQLite 数据库。

由于浏览器安全限制，网页可能无法直接跳转到 edge:// 页面。如果按钮被拦截，请复制 edge://settings/searchEngines 到地址栏。进入页面后打开 Console，直接粘贴上面的一行脚本。

数据格式 / JSON Format

导出文件可以作为备份，也可以在其他设备重新导入。本页会自动保存在当前浏览器的 localStorage 中。

[{"name":"Google","shortcut":"g","url":"https://www.google.com/search?q=%s","enabled":true}]
